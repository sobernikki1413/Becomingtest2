# Becoming — Ocean Sunset Development Preview

This is a browser-based development preview, not a finished mobile app.

## What changed
- Deep ocean-blue backgrounds and dark teal cards throughout the interface
- Soft ivory text, blush-pink accents, and improved dark-mode contrast
- Existing approved welcome-card gradient retained
- Existing interactions and local browser storage preserved

## GitHub Pages on iPhone
Upload **index.html** to the root of the existing **Becomingtest-** test repository, replacing the old index.html, then commit the change. GitHub Pages will redeploy. This does not modify your original Soft Landing repository.

## Privacy
This preview stores entries in the browser on the current device, and browser data may be cleared. Do not enter sensitive personal information during testing.
